# Availoom visual and interaction decisions

Brand: **Availoom**. Tagline: **Your AI limits, at a glance.** The original reserve-gauge mark represents remaining capacity and stays legible in the thin strip and monochrome menu bar.

## Direction

A quiet desktop instrument: warm graphite, ivory light mode and one brass accent. The primary surface is a 44 px high horizontal strip inside a transparent native window, not a dashboard. Secondary information appears in a rounded, anchored panel. Typography uses the system font, tabular quota numbers and a clear hierarchy between measurement, reset, and provenance.

## Principles

- Unknown data gets a designed empty state and useful next action, not a decorative percentage.
- Every real reading identifies its source, account, age, window and product context.
- Synthetic readings exist only in automated tests; the shipped app has no demo mode.
- Small provider glyphs are original vector drawings, not copied brand assets.
- No perpetual decoration or celebration. Motion is brief and respects system/app preferences.
- One accent guides actions; provider colors distinguish services without carrying state alone.
- No remote fonts, images, analytics, CDN dependencies or external UI scripts.

## Interaction

Provider → details → explicit read consent. Settings are a distinct contextual panel. The toolbar stays reachable by keyboard; Escape returns focus. Account reads are manual, bounded and cancellable. No hidden authorization on startup, preview, settings or executable discovery.

## Review before distribution

Validate native screen edges and multiple monitor scaling, physical VoiceOver workflows, larger text, App Store constraints of transparent windows, upstream authentication terms, provider naming/marks and each target OS. Local preview quality is not a claim of complete product readiness.
